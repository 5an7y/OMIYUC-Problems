# Problema

Se te darán $N$ números enteros y deberás imprimir el valor absoluto de cada uno.

# Entrada

Un entero $N$ indicando la cantidad de números. En la siguiente línea $N$ números enteros $x_i$.

# Salida

El valor absoluto de los $N$ números, en el mismo orden, separados por espacios.

# Ejemplos

||input
5
-1 1 2 -2 4
||output
1 1 2 2 4
||input
3
-3 2 -1
||output
3 2 1
||input
1
0
||output
0
||end

# Limites

- $0 < N < 100$
- $|x_i| < 1000$
