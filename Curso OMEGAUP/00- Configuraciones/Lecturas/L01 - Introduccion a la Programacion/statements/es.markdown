Esta es una **lectura** diseñada para el curso de la OMI Yucatán. El curso tiene como propósito enseñar los principios básicos de programación competitiva en C++.

# Introducción al curso

Este curso te va a enseñar a programar en C++ desde cero. No necesitas saber nada de programación para empezar — solo ganas de aprender.

Al terminar vas a poder resolver problemas de programación competitiva: leer datos, procesarlos y dar una respuesta correcta. Eso es exactamente lo que hacen los participantes de la Olimpiada Mexicana de Informática.

## ¿Qué necesitas para programar?

Solo dos cosas:

1. **Un lugar donde escribir tu código** — como Word, pero para código.
2. **Un compilador** — el programa que convierte tu código en algo que la computadora puede ejecutar.

En las siguientes lecturas verás cuatro opciones para hacer esto.

## Las cuatro opciones

| Opción | ¿Por qué usarla? |
|--------|-----------------|
| **CodeChef** ⭐ | Online, sin instalación. Además de correr código, tiene una función para ver tu programa ejecutándose paso a paso, lo cual ayuda mucho cuando algo no sale como esperabas. |
| **online-cpp.com** | La más sencilla de las cuatro. Solo abres el navegador y escribes. Sin cuentas, sin configuración. |
| **Compilador de OmegaUp** | Está integrado directamente en la plataforma donde resuelves los problemas del curso. Útil para probar algo rápido, pero tiene más botones y opciones que al principio no necesitas. |
| **CodeBlocks** | Se instala en tu computadora. Una vez instalado no necesitas internet. Opción para quien prefiere trabajar de forma local. |

## Lo más importante: elige cualquiera

**No importa cuál uses — el curso funciona igual con las cuatro opciones.**

El contenido del curso no asume que tienes instalado X ni que usas Y. Todo lo que aprendas aplica sin importar tu editor: el código de C++ es el mismo en todos lados.

Puedes cambiar de editor en cualquier momento, usar varios al mismo tiempo, o empezar con uno y migrar a otro cuando quieras. No hay consecuencias.

**Recomendamos empezar con CodeChef** por el visualizador paso a paso, pero si prefieres algo más simple para tu primer programa, online-cpp.com funciona perfecto.
