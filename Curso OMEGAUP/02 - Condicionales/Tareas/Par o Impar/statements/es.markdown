*Este problema es una* ***tarea*** *diseñada para el curso de la OMI Yucatán. El curso tiene como propósito enseñar los principios básicos de programación competitiva en C++.*

# Problema

Dado un número entero $N$, determina si es par o impar.

# Entrada

Un entero $N$.

# Salida

Imprime `Par` si $N$ es par, o `Impar` si $N$ es impar.

# Ejemplos

||input
4
||output
Par
||input
7
||output
Impar
||input
0
||output
Par
||end

# Limites

- $0 \leq N \leq 10^9$
