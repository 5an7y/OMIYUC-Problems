# Problema

Separar el ultimo digito de un numero entero.

# Entrada

Se te dara un numero entero $a$.

# Salida

Deberas sacar el numero sin su ultimo digito y el ultimo digito de $a$.

# Ejemplos

||input
312
||output
31 2
||input
5341
||output
534 1
||input
4233
||output
423 3
||end

# Limites

- $10 \leq a \leq 10^6$
