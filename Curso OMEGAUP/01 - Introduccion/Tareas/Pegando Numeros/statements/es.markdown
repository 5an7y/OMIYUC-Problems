# Problema

En este problema lo unico que tendras que hacer es pegar dos numeros.

# Entrada

Se te daran dos numeros enteros $a$ y $b$.

# Salida

Deberas sacar un unico numero que se forma de pegar $a$ y $b$.

# Ejemplos

||input
123 456
||output
123456
||input
32 23
||output
3223
||input
10 10
||output
1010
||end

# Limites

- $1 \leq a, b \leq 10^6$
