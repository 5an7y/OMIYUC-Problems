# Problema

Deberás hacer un código que saque el módulo entre dos números.

# Entrada

Se te darán dos números enteros $a$ y $b$ separados por un espacio.

# Salida

Deberás imprimir el resultado de la operación $a \% b$.

# Ejemplos

||input
10 3
||output
1
||description
El residuo de dividir 10 entre 3 es 1.
||input
49 7
||output
0
||input
3244 163
||output
147
||input
4390 32
||output
6
||input
24364 342
||output
82
||end

# Limites

- $1 \leq a, b \leq 10^5$.
