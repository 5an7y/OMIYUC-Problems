# Problema

Tu robot programable aprendió a saludar con `”Hola Mundo”`, pero olvidó cómo despedirse correctamente. Ayúdalo a imprimir la despedida en dos líneas separadas: primero `”Adios”` y luego `”Mundo!”`.

# Ejemplo

Los problemas suelen contar con un área de ejemplos donde se muestra como seria la entrada (que en este caso no hay) y cual debería ser la salida (en este caso el texto).

||input
||output
Adios
Mundo!
||end

Si todo está bien el problema debería darte 100 puntos. Si algo salió mal asegúrate de leer bien toda la lección e imprimir el texto tal como se muestra en el recuadro de arriba. Nota que no hay un espacio antes del "Mundo!".
